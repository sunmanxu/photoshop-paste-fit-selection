# 粘贴贴合选区（Photoshop 脚本）

把剪贴板里的图片粘贴到当前文档，并自动**非等比拉伸、严丝合缝地铺满**你事先画好的矩形选区，左上角对齐。

配合「PS 里复制选区 → 网页/AI 改图 → 复制结果 → 跑这个脚本贴回原位」的工作流使用。

## 用法（不需要安装）

1. 在 Photoshop 里画一个矩形选区（不画也行，会退化成普通粘贴）
2. 复制一张图片（网页、截图、文件夹里的都行）
3. 菜单 `文件 → 脚本 → 浏览`，选中 `粘贴贴合选区.jsx` 运行

## 想让它常驻菜单（可选）

把 `粘贴贴合选区.jsx` 复制到：

```
C:\Program Files\Adobe\Adobe Photoshop 2025\Presets\Scripts\
```

重启 Photoshop，之后 `文件 → 脚本` 里会直接出现「粘贴贴合选区」。

## 行为

- **有选区**：粘贴 → 转成智能对象（可无损缩放）→ 按选区宽高非等比缩放 → 左上角精确对齐，最多迭代 4 次收敛
- **没选区**：普通粘贴，并提示「已粘贴，但没有选区，按原尺寸放置」
- **剪贴板里不是图片**：提示先复制一张图片
- **没打开文档**：提示先打开文档

## 兼容

Adobe Photoshop 2022 及以上（ExtendScript 的 `文件 → 脚本` 通道至今保留），PS 2025 实测可跑。

## 注意

- 粘贴进来的图层如果被锁定，先解锁或栅格化再运行
- 缩放用 `AnchorPosition.TOPLEFT` 加迭代平移，所以边缘不会留 1px 缝隙
